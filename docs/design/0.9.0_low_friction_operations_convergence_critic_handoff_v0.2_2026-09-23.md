2. BLOCKER 1 — GH READ SCOPE
==================================================

v0.2 已删除 global direct allow：
- gh repo view
- gh pr view
- gh issue view
- gh run view

原因：
current execpolicy 是 prefix matching；
这些 view family 有 positional target 或 targeted-object surface。

v0.2 只保留 candidate direct forms：
gh auth status --
gh pr list --
gh pr status --
gh issue list --
gh issue status --
gh run list --

请复核：
1. retained no-positional status/list shape 是否确实不能通过 suffix 选择另一个 repository；
2. --repo 必须位于 terminator 前，因此不会被 retained prefix allow 吸收，这一判断是否成立；
3. gh auth status -- 是否阻止 suffix --show-token 被解析成 option；
4. cross-repo/private negative matrix 是否足够：
   - gh repo view other/private
   - cross-repo PR URL
   - cross-repo issue URL
   - gh pr list/status --repo other/private
   - gh issue list/status --repo other/private
   - gh run list --repo other/private
   - gh auth status --show-token
   - gh api repos/other/private
5. 是否还有 retained shape 能直接扩大 private/repository read scope。

如果某个 retained command 不能安全 direct allow：
最小关闭方式是把它留在 prompt，
不是新增 Bridge read wrapper。

3. BLOCKER 2 — PUBLISH-CURRENT-BRANCH EXACT EFFECT
==================================================

v0.2 仍只有一个 bounded publisher：

ai-bridge host publish-current-branch --expected-repo <canonical-repo-identity> --expected-branch <branch>

expected-repo / expected-branch 只能 equality assert，
不能选择 remote/refspec/effect。

请复核：

A. canonical repo / destination
- current repo identity 从 cwd/current Git repo 推导；
- git remote get-url --all origin；
- git remote get-url --push --all origin；
- exactly one fetch URL + exactly one push URL；
- insteadOf / pushInsteadOf 已展开；
- push/fetch identity mismatch fail closed；
- multiple pushurl / destination fail closed；
- unknown custom remote-helper / non-default receivepack 不被 trusted helper静默执行。

B. exact branch/ref
- current symbolic branch == expected branch；
- upstream remote == origin；
- upstream merge == refs/heads/<current>；
- remote same-name branch 已存在；
- behind/diverged fail closed；
- captured HEAD + final pre-mutation branch/HEAD/destination recheck；
- authorized-A -> checkout-B fail closed；
- helper内部只产生 captured_oid:refs/heads/<expected-branch>。

C. config-expanded effects
- remote.origin.mirror=true -> fail closed；
- --no-follow-tags 防止 push.followTags；
- --no-recurse-submodules 防止 push.recurseSubmodules / submodule.recurse；
- inherited push.pushOption 清空；
- signing/external program 不成为额外 local executable path；
- 不允许 extra refspec / tags / all / mirror / upstream / force / delete。

D. pre-push hook
- helper读取 effective hook path，包括 core.hooksPath；
- active executable pre-push hook -> no mutation，回 ordinary approval；
- active hook 不得通过 trusted ai-bridge 变成 sandbox-bypass；
- Review Executor process-local pre-push guard 必须被识别并使 generic publisher拒绝；
- no-hook internal push 只用于确保 trusted helper不执行突然出现的 hook，不能绕过已经存在的 hook。

E. Review watcher ownership
- existing reviewed_runner validation/publisher 不变；
- generic publisher 不能成为 Review Executor 绕过入口。

只要 exact-effect contract 成立，不要要求 generic Git facade、auth DB、permission token 或新状态机。

4. BLOCKER 3 — REVIEWED WORKTREE FROZEN SCOPE
==================================================

v0.2 仍只增加 existing Reviewed Handoff 下的一个 materialize operation。

Canonical frozen source：

1. exact worktree locator：
   automation/reviewed_handoff/tasks/<task_key>/REQUEST.md
   -> ## User constraints
   -> exactly one reserved line:
      - Reviewed worktree locator: <normalized absolute path>

2. frozen base：
   existing CURRENT.json:
   - task_key
   - base_branch
   - base_commit

3. branch：
   only derived as reviewed/<task_key>

Caller assertions：
- expected-repo
- expected-worktree
- expected-base-ref

这些只能 equality assert，
不得成为 free selector。

请复核：

A. authorization boundary
- repo artifact只证明 frozen scope；
- current-user kickoff/resume才提供 authorization；
- helper不保存 auth DB/token/ledger；
- task key本身不能冒充授权。

B. path
- sibling worktree 可用；
- /tmp worktree 可用；
- wrong sibling/path fail closed；
- changed symlink resolution fail closed；
- occupied unrelated path/worktree fail closed；
- 不 fallback 到别的 sibling/tmp/canonical checkout。

C. bootstrap
- base ref由 CURRENT.base_branch 派生；
- exact start commit = CURRENT.base_commit；
- base lineage真实验证；
- branch = reviewed/<task_key>；
- bootstrap mode 遇到 unexpected remote reviewed branch 必须 fail。

D. resume
- remote origin/reviewed/<task_key> 已存在；
- remote task CURRENT metadata task_key/base_commit/base_branch 匹配 canonical frozen task；
- remote head descends from frozen base；
- local branch missing -> exact rematerialize；
- local branch exists and exact -> idempotent；
- local/remote branch tip ambiguity -> fail；
- wrong lineage -> fail。

E. rollback
- 只清理由本次 invocation 新建且仍证明 ownership 的 local objects；
- 不删 remote；
- 不 reset/clean；
- 不删 pre-existing branch/worktree；
- ownership不明则保留 partial state + evidence。

不得要求新的 Reviewed schema family、permission database、ledger 或 workflow class。
