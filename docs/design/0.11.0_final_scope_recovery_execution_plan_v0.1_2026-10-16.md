## 6. Phase 0：先确定 thread 投递机制

Phase 0 是开发机制探针，不是 final Gate，只能在 approved Kickoff 后运行。

### 6.1 当前运行身份

重新核 actual Codex version、CODEX_HOME、shared app-server daemon/remote endpoint、disposable thread exact id/status/path、实际 server version，以及 `thread/resume` / `thread/inject_items` / `turn/start` 支持。

### 6.2 shared writer 是 A/B 共用前提

只连接**拥有或共享 exact thread** 的官方 app-server 路径。优先复用当前 Codex local daemon / explicit remote session discovery；不得为 live thread 再启动 embedded app-server 与已有 owner 并发写 rollout。

若只能另起 embedded writer：`P0_WRITER_BINDING=UNSAFE_UNAVAILABLE`，停止 P0-A/P0-B，回 Planner/Critic。

### 6.3 P0-A：idle exact thread + `thread/inject_items`

前置：

- disposable thread，无真实任务/私有数据；
- exact id + shared writer 已核；
- thread idle；
- active turn 时只返回 `DEFER_ACTIVE_TURN`，不 inject，因为 0.160.1 active-turn inject 会进入 active input queue。

操作：注入固定 assistant-role progress item，内容来自 canonical normalized snapshot，不是 user message。

PASS 必须同时：

1. 原 task thread UI **自动出现**该 progress；
2. 无 `turn.started`、无 model network request、无新增 token usage；
3. UI 不是 user message；
4. exact thread/run/task binding 不变；
5. reconnect/resume 后同一 progress 仍可见且不重复；
6. active-turn 负例只 defer；
7. 不出现第二 writer。

只有 shared writer/identity 已安全但 method 不支持、UI 不可见或 reconnect 不可见时才切 P0-B。writer/identity/并发归属不安全时不能切 B。

### 6.4 P0-B：idle exact thread bounded `turn/start`

只在合法切换条件成立时，同一 disposable thread 最多一次：

- active -> defer，绝不 `turn/steer`；
- 固定 Bridge progress tool-output/application context，不伪 user input；
- model 只渲染 normalized snapshot，不估 ETA/比例、不决定下一步；
- 不允许工具调用/文件/网络/任务 side effect；
- 记录 token、耗时、context 增量；
- reconnect 后 UI 一致。

若工具行为、scope 变化、多 turn 或不可控 context 污染出现，FAIL。

P0-B 也失败 -> `THREAD_PROGRESS_ROUTE=UNSUPPORTED_WITH_EVIDENCE`，停止；不得 email/manual latest 降级冒充。

### 6.5 `thread/queue/add` 不作主路

0.160.1 为实验性且输入是 `UserInput`。本包禁止用它把系统 progress 伪装成 user submission。

## 7. exact thread identity 两条来源

### 7.1 已存在 thread 内启动

真实进程环境 `CODEX_THREAD_ID` 只是 candidate identity；随后用 current shared app-server resume/read 核 exact id 与 repo/Goal/run。Repo 文件、标题/cwd/时间近似都不能指定 thread id。

### 7.2 Bridge 启动 `codex exec`

当前 Lite/Reviewed child 需要 Persistent Run projection 时：

- 使用官方 JSONL event mode；
- 只从第一个唯一 `thread.started.thread_id` 取得 child thread；
- 不用 launcher ambient `CODEX_THREAD_ID` 冒充 child；
- raw JSONL 留机器本地 evidence；
- 非-Persistent task UX 不因抓 id 退化；
- missing/multiple/invalid event fail closed，不猜 thread。

### 7.3 machine-local binding

保存于 Bridge state root 下 Persistent Run run identity，字段仅包括 repo/task/run/Goal hash、thread id、identity source、Codex executable/version、CODEX_HOME、app-server target kind（不保存 auth token）、bound time。

这是 observation binding，不是 auth DB。

## 8. observation 与 last logical delivery 分离

保留 `latest.json` / bounded history 作为 observation。另存最小 logical-delivery state：

- last delivered snapshot/time/reason
- last successful thread projection identity
- progress email result（若启用）

普通 count/fraction 只更新 observation。

Immediate：

- start/resume
- meaningful stage transition
- first stalled/blocked/failed/runtime completion
- material ETA

material ETA：

`abs(expected_finish_delta) >= max(15 minutes, 25% of prior remaining time)`

known ↔ UNKNOWN 永远 material。

普通 active progress 只有距**last delivered**达到 interval 才投递。默认 3600 秒；任务可给有理由的 bounded cadence；无任务理由不得低于 900 秒。

每 5 分钟 observation 不能把 60 分钟 cadence 永久饿死。

thread/email/local 使用同一个 canonical snapshot；email 失败不影响 thread/run，thread 失败不能自动用 email 冒充。

## 9. lifecycle-bound report loop

正常入口可为：

`ai-bridge persistent-run report-loop --target <repo> --goal <goal> --progress <source>`

语义固定：

- foreground；
- 不 daemonize；
- 不发现下一任务；
- 不改资源/scope；
- tick 只读 progress、normalize、decision、projection；
- runtime terminal 后最后报告并退出；
- SIGTERM/INT 正常清理。

### tmux owner

同一 canonical launch script 启 actual work + reporter child，记录 PID，trap 在 owner/work exit/failure/signal 时 kill/wait reporter。Reporter 不单独保持 tmux session。

### scheduler owner

job script/native orchestrator 持有 reporter child；job/cgroup + cleanup trap 收尾。已有 heartbeat 若保证 interval 调 one-shot reporter，可不用 loop。Bridge 不套 tmux。

### existing service owner

只有现有 supervisor 能管理 sidecar child 才支持；不为 Bridge 新建 system service。不能证明 cleanup -> 该 topology 不 claim proactive PASS。

Observation frequency 与用户 report cadence 分离。

## 11. Machine SMTP profile 与安全

Machine default：

`AI_BRIDGE_STATE_HOME/private/notifier.env`；若 state home 未显式设置，使用既有 `~/.ai-bridge/private/notifier.env`。

Project `.ai-bridge/private/notifier.env` 保留 override。

优先级：`machine < project < process env`。

Sync：

1. source 仍为合法 `AI_BRIDGE_PRIVATE_RCLONE_SOURCE`；
2. target 必须在 machine private root；
3. parent/target/temp 拒绝 symlink/reparse/path escape；
4. POSIX private dir 0700、file 0600 + current-user ownership；
5. Windows/其他平台若不能证明当前用户私密边界则 no live use；
6. rclone 先写同目录安全 temp，验证 keys，再 restrict + atomic replace；
7. stdout/stderr 不输出 password/secret 内容；
8. project override 同样拒绝 symlink/escape 且保持 Git ignored。

Progress email 直接渲染 stage/status/completed/total/fraction/ETA/basis/uncertainty/last real progress/progress delta；ETA 不可靠时写“预计完成时间未知”。

## 14. Deterministic regression

### Persistent Run

- start/resume immediate
- stage immediate
- stalled/blocked/failed/runtime-complete immediate
- fraction 连续变化 < interval 全 suppress
- 每 5 分钟 observation，60 分钟基于 last-delivered 必须 cadence deliver
- denominator invalid 不造 fraction
- ETA known↔UNKNOWN immediate
- ETA 小变化 suppress / material threshold deliver
- 无理由 interval <900 fail/normalize；测试用 clock injection，不开放生产 escape
- no cancel/restart/resource expansion
- observation/history 与 delivery state 分离

### lifecycle

- owner start/tick/exit，reporter cleanup
- owner signal/failure cleanup
- runtime terminal loop自退
- no owner -> 不自建 daemon

### thread

- ambient ID 只用于 existing-thread launch
- Bridge child 唯一 thread.started
- ambient 与 child 冲突时 child event胜出
- missing/multiple/invalid event fail
- repo fake thread id无效
- active -> defer
- shared daemon存在时禁止 embedded second writer
- reconnect same id
- send_message_to_user_async 不进入 route

### Notifications/private

四 intent 组合、missing fields no-send、self-asserted auth无效、完整 progress body、UNKNOWN 中文、runtime != semantic、wrong semantic owner拒绝、dedupe/retry、machine/project/env precedence、0600/0700、symlink/path escape、temp atomic replace、invalid secret不覆盖旧配置、不回显 secret。

### Host/wrapper

safe allow + malicious neighbor prompt；dangerous Git不放宽；no read wrapper；plugin-replay narrow consumer smoke；ordinary plugin flow仍 official。

### should-not-change

全量 tests/CI + Lite readiness、Reviewed bootstrap/resume/publish-first/watcher、Control generic prompt compatibility、partial clone、双脏 worktree、sync/publisher、0.10 refusal、Persistent Run install/latest、Notifier historical milestone/blocked。
