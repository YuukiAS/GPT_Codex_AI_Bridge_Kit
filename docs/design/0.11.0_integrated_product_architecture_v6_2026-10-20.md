## 2. 本轮唯一产品修复语义

automatic notification 使用 writing-fidelity + response-clarity。

完整内部 NotificationRequest 保持不变，用于权限、去重、审计和机械保真。reader-facing projection 默认不展示这些内部机器字段：

- consumer
- fact_class
- decision_authority
- runtime_id
- source_event_id
- schema

- one model turn per logical delivery；
- model retry = 0；
- Clear Writing 最多 90 秒；
- automatic deliver 总墙钟最多 120 秒；
- deterministic fallback；
- 通知失败不改变业务状态、不杀 primary child、不回滚 Review/Control transition。
