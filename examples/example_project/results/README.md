# Results Directory

Task outputs use the same task key as `prompts/tasks/<task_key>.md`.

Example:

```text
prompts/tasks/002_fix_ci.md
results/002_fix_ci/result.md
results/002_fix_ci/review.md
results/002_fix_ci/MANIFEST.md
```

Keep large logs, tables, figures, archives, and intermediate outputs under the matching `results/<task_key>/` directory.
