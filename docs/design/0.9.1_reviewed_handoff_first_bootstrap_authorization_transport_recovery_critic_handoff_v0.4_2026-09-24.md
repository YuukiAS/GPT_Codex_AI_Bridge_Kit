Plan v0.3 used:

-> inspect refs/remotes/origin/reviewed/<task_key>

- --all skips remote.<name>.skipFetchAll=true;

Therefore local absence is authoritative only under a canonical origin fetch profile.

Review only whether v0.4 closes this correctly.
