## 3. F05 exact closure to verify

### A. Exact candidate root

v0.2 冻结：

```text
CANDIDATE_ROOT =
/users/a/e/aereinh/.ai-bridge/candidates/bridge-core--execution-reliability-closure/<FINAL_SHA>

CANDIDATE_SOURCE = <CANDIDATE_ROOT>/source
CANDIDATE_VENV   = <CANDIDATE_ROOT>/venv
LIVE_GATE_DIR    = <CANDIDATE_ROOT>/live-gate
```

Candidate source 只从 canonical Bridge checkout 的 exact final commit 用本地
`git archive` materialize。

不允许：

- network clone/fetch；
- new Git worktree/branch；
- 覆盖已有不匹配 candidate root。

请检查这是否足够绑定 exact final candidate。

### B. Local/no-network candidate install

v0.2 冻结：

```text
<BASE_PYTHON> -m venv <CANDIDATE_VENV>

PIP_NO_INDEX=1
PIP_DISABLE_PIP_VERSION_CHECK=1
<CANDIDATE_VENV>/bin/python -m pip install   --no-index   --no-deps   --no-build-isolation   <CANDIDATE_SOURCE>
```

如果 local venv 已有 build tooling 不满足 `pyproject.toml`，必须：

`STAGE_B_LOCAL_BUILD_TOOLING_UNAVAILABLE`

不得因为 Gate 需要运行就从 PyPI/index 拉 setuptools/wheel/build deps。

请核实这是否满足“isolated candidate activation，但不虚构额外网络授权”。
