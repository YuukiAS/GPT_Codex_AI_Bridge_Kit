## 7. One bounded current-branch publisher

Implement exactly one internal Machine Policy operation:

```text
ai-bridge host publish-current-branch   --expected-repo <canonical-repo-identity>   --expected-branch <branch>
```

The two arguments are equality assertions only.

The helper must derive repository/current branch/origin/same-name remote ref from live Git state and must preserve every v0.3 fence.

### Exact effect

Before mutation require:

- canonical current repo identity;
- exactly one effective fetch URL and one effective push URL;
- fetch/push identity equality;
- expected-repo equality;
- symbolic current branch == expected-branch;
- upstream remote == `origin`;
- upstream merge == `refs/heads/<current>`;
- remote same-name branch already exists;
- behind == 0 and remote is ancestor of captured HEAD;
- no mirror;
- no extra refspec/tag/all/upstream/force/delete;
- follow-tags disabled for this invocation;
- recursive submodule push disabled;
- push options neutralized;
- signing executable side effects disabled;
- no active effective pre-push hook;
- final branch/HEAD/destination/config recheck immediately before push.

The generated ref update is exactly:

```text
<captured-local-oid>:refs/heads/<expected-branch>
```

### Transport-execution fence

For the trusted low-friction path:

- non-empty inherited `GIT_SSH` or `GIT_SSH_COMMAND` -> fail closed;
- any effective `core.sshCommand` -> fail closed;
- caller `GIT_SSH_VARIANT` is not inherited by mutation;
- standard host/user `~/.ssh/config` and `SSH_AUTH_SOCK` remain usable;
- system/global HTTPS credential helpers remain usable;
- local/worktree/command-scope `credential.helper` and URL-scoped helper injection -> fail closed;
- inherited `GIT_ASKPASS` / `SSH_ASKPASS` -> fail closed;
- any effective `core.askPass` -> fail closed;
- mutation uses `GIT_TERMINAL_PROMPT=0`;
- safety-critical command/config-source overrides are either rejected or proven non-critical and removed from the mutation environment;
- `GIT_CONFIG_GLOBAL`, `GIT_CONFIG_SYSTEM`, `GIT_CONFIG_NOSYSTEM`, and `GIT_CONFIG_COUNT` families are covered by deterministic regressions.

Custom transports fall back to ordinary raw `git push` approval. Do not add another wrapper.

### Reviewed watcher authority

A Review Executor running under `reviewed_runner.push_guard_environment()` must cause the generic publisher to refuse before mutation.

Only the existing reviewed_runner validation/publication path may publish canonical Review Executor progress.

### Main raw push rule

After the bounded publisher passes its final-candidate gates, remove the global raw direct allow for `git push origin main`. Main remains low-friction through the bounded publisher.
