## 1. 正面完成标准

最终唯一 C' 必须同时实现并证明：

1. Persistent Run 由真实 run/process lifetime owner 持有 ticker，默认约 60 分钟主动向**原 Codex task thread**报告；无任务理由不得低于 15 分钟。
2. start/resume、重要 stage、stalled/blocked/failed/runtime completion、material ETA 可提前。
3. observation 与 last logical delivery 分离；fraction/count小变化不刷屏，频繁 observation 不饿死 cadence。
4. exact thread 仅：
   - 已存在 thread 内真实 `CODEX_THREAD_ID` + shared app-server复核；
   - Bridge child 官方 `thread.started.thread_id`。
   不按标题/cwd/时间/repo文件猜。
5. shared owning app-server安全成立才写 thread；不启第二 embedded writer。
6. P0-A 优先验证 idle `thread/inject_items` 无模型、UI-visible、reconnect；active只defer。
7. A合法失败才 P0-B：same disposable idle thread、最多一 bounded `turn/start` render turn、非user input、无工具/任务side effect、记录token/cost/context；active不steer。
8. A/B都失败就 `UNSUPPORTED_WITH_EVIDENCE` 停止，不用email/manual latest冒充。
9. `send_message_to_user_async` 仅研究参考：UnderDevelopment/default-off/DirectModelOnly，不作为成熟 Bridge route。
10. machine SMTP profile一处配置多项目消费，project profile只兼容覆盖；secret路径/权限/symlink fail closed。
11. `Progress email` 与 `Semantic completion email` 独立、缺省DISABLED；live normal entry实际重读 frozen intent。
12. progress mail直接含 stage/status/completed/total/fraction/ETA/basis/uncertainty/last real progress/progress delta；无ETA明确未知。
13. runtime completion不等于Goal completion；semantic completion mail仅现有semantic owner + positive criteria + intent。
14. Host Policy只allow真实证明安全的native reads；不安全保持gated；不造read wrapper。
15. `plugin-replay` KEEP_NARROW，不扩成通用Reviewer。
16. G01–G05、G07–G13不降级；G06/G14按Plan恢复。
17. 所有生产修改后冻结新C'；final gates/CI/installed Bridge/Machine Policy/Codex identity只绑定C'。

## 4. P0 route contract

获批准Kickoff后，先同一 disposable thread P0-A；只有 writer/identity安全而route/UI不满足时才P0-B。writer不安全时A/B都停。P0只是开发机制选择，不是final Gate。

最终C'仍须重新证明真实UI可见、reconnect、非user message、active defer与canonical snapshot一致。

## 5. Reporter contract

- report可频繁观察；
- last observed / last delivered独立；
- user cadence基于last delivered；
- fraction/count小变化只观察；
- immediate事件/material ETA按Plan；
- foreground report-loop由actual run owner持有；
- owner/terminal/signal后确定性cleanup；
- owner无法绑定则该topology不claim proactive reporting；
- reporter不能cancel/restart/扩资源/改Goal。

## 6. Notification contract

Frozen Goal/task：

`Progress email: ENABLED | DISABLED`  
`Semantic completion email: ENABLED | DISABLED`

缺失=DISABLED。Live progress/semantic completion normal entry都必须重读该source；progress JSON self-asserted auth无效。

SMTP优先级：machine default < project override < process env。Machine/private路径必须安全，不回显secret。
