3. FIRST-BOOTSTRAP COMMAND / SINGLE INITIALIZER
==================================================

v0.2 proposes one nested Reviewed Handoff command:

ai-bridge reviewed-handoff task bootstrap

Required assertions:
- target canonical repo;
- semantic task key;
- expected repo;
- exact worktree;
- expected base ref;
- expected base commit;
- existing task-init metadata/options.

No --branch argument.
Branch is still derived as reviewed/<task_key>.

The command must:
1. preflight exact scope;
2. create exact branch/worktree;
3. only inside reviewed worktree call the same internal task initializer used by task init;
4. REQUEST freezes exact worktree;
5. CURRENT freezes original source base branch/commit;
6. canonical main remains free of bootstrap control files.

Critic should check that this is the smallest safe extra execution surface and not a disguised generic Git wrapper.

Do not require a new payload schema/database merely to reduce CLI arguments.

==================================================
4. FB-B2-REMOTE-RESUME-SOURCE
==================================================

v0.2 defines one task-scope discovery rule.

Case 1 — complete local metadata exists:
- both local REQUEST + CURRENT exist;
- validate/use them;
- for resume cross-check exact remote frozen identity/lineage before mutation.

Case 2 — both local REQUEST + CURRENT absent:
- derive only origin/reviewed/<task_key>;
- fetch exact remote branch;
- before checkout, read REQUEST/CURRENT directly from that remote commit tree;
- validate:
  - task_key;
  - base_branch;
  - base_commit;
  - worktree locator;
  - caller repo/path/base assertions;
  - remote lineage;
- only then materialize local branch/worktree.

Case 3 — only one local metadata file exists:
- fail LOCAL_TASK_METADATA_PARTIAL;
- do not silently fall back to remote.

Remote branch name alone never proves task identity.

No remote metadata is copied into canonical main.

Review whether this fully closes the v0.1 contradiction:

first metadata exists only on reviewed branch
AND
later local-loss rematerialization still works.
