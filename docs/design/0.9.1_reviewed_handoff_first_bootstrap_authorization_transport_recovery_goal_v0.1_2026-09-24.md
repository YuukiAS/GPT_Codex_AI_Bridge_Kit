## 4. Required hardening

### Repo-local bootstrap

Trusted normal entry operates on the cwd Git repo only.

No trusted cross-repo target selection.

Derived:

```text
branch = reviewed/<task_key>
worktree = <cwd-repo-parent>/<cwd-repo-directory-name>-<task_key>
base = current local refs/remotes/origin/main OID
```

`expected_repo` and `expected_base_commit` are assertions, not selectors.

### RL-B1 executable fence

Before the first mutation, fail closed for executable paths reachable by the retained helper sequence, including:

- `reference-transaction`;
- `post-checkout`;
- `post-index-change`;
- effective `core.hooksPath`;
- external `filter.*.smudge`;
- external `filter.*.process`;
- external `core.fsmonitor` if still reachable by retained status/rollback behavior.

An equivalent simpler implementation may remove a reachable command path instead of adding a scanner.

### RL-B1 output-path fence

Before writing task/result state, reject symlink/non-directory redirection through the protected `automation/.../tasks/<task_key>` and `results/<task_key>` chains.

Do not follow or repair repository-owned symlinks.

### RL-B2 strict remote profile

Trusted bootstrap requires:

```text
configured remotes = exactly ["origin"]

remote.origin.skipFetchAll = unset/false
remote.origin.skipDefaultUpdate = unset/false

remote.origin.fetch =
+refs/heads/*:refs/remotes/origin/*
```

exactly one fetch refspec.

Any second remote, custom/multiple/negative refspec, or skip flag exits the trusted path.

No Git config mutation.

### Network boundary

The helper itself performs zero network operations.

Before the real gate, repo-local Codex uses the already-allowlisted:

```text
git fetch --all --prune
```

Then bootstrap validates local remote-tracking state only.
