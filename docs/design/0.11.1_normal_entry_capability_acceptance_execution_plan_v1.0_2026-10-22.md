## 1. 不变的产品承诺

本 Plan完整继承 v0.3：

- Host：GitHub HTTPS-only bounded sync；真实 execpolicy `no_match` 不伪装成 prompt；五个正式 Git wrapper 的机械边界与 Codex policy边界分开。
- Persistent：项目 owner 决定 progress 是否可量化；真实 producer、publication freshness、platform/unreadable/overdue/runtime-stalled 分离；ETA 只使用真实近期速度；status/history/ETA/mail 同一可信快照。
- durable-first：child start事实先落盘再发 start；wait返回后先有界读取最终 progress、保存 exit/terminal，再尝试 terminal通知。
- budget：同一 run binding 五个普通 slot + 一个 terminal reserved slot；外部 helper 前先持久占 slot；成功/失败/`DELIVERY_UNKNOWN`/crash/recovery 不退款；budgeted retry无新用户授权禁止。
- Notifier：只验证 permit，不成为预算 owner。
- 十二项正式能力有限正常入口验收；同一 final candidate；Program Run唯一有意排除；正式 release不自动授权。

## 2. budget permit 信任链实现合同

这是已批准设计的实现细化，不新增产品机制。

对 budgeted Persistent 通知，caller不得传一个任意 `binding_path` 就获得外部调用权限。permit验证必须至少满足：

1. 从当前正式 machine state root + exact `repo_realpath` + `run_key` 派生 canonical run binding locator，或对 caller locator做等价严格校验；
2. binding schema、Goal source/hash、run key、launch id 与当前 supervisor一致；
3. permit绑定 `launch_id`、`source_event_id`、`slot_id`、cap identity 与 `no_retry=true`；
4. slot必须已经在 canonical binding 中原子持久占用，且未被另一 event复用；
5. nonterminal最多5席；terminal专席只能由真实 runtime terminal消费；
6. Notifier helper在 Clear Writing/model 或 SMTP transport启动前验证 permit；
7. budgeted claim若通过 `retry_event` 进入且没有新用户授权，返回 NOT_RETRYABLE，不启动模型/SMTP；
8. invalid/missing/stale/wrong-root/wrong-launch/wrong-event/wrong-slot permit全部 fail closed，业务 child与本地 lifecycle/progress继续。

不得新增 database、central budget service、daemon 或跨 workflow event bus。

## 8. Persistent最终Gate：不可替代

最终合法任务一旦找到，必须直接观察：

`persistent-run start → real primary child → real project progress producer → supervisor → status/history/ETA → run-scoped slot reservation → shared Notifier → one-shot Clear Writing → Gmail → final progress/terminal`

并证明：
- ≥3个真实点跨≥10分钟产生ETA；
- producer overdue不是业务stalled；恢复后正常；
- platform/unreadable与overdue分开；
- status/history/mail同源；
- final progress和exit code durable-first；
- 五个nonterminal slots真实消费；
- 第六个额外合法nonterminal candidate预算suppressed；
- terminal使用保留slot；
- model invocations≤6，SMTP starts≤6；
- suppressed event model=0/SMTP=0；
- failure/DELIVERY_UNKNOWN/crash/recovery/retry不返slot、不增调用；
- start/resume不重复child；
- runtime terminal不推断Goal semantic completion。

六/七事件deterministic regression只证明预算算法，不替代这里。
