## AGENTS 边界

当前 checkpoint 有一个必须修复的实现问题，但它不是“代码太多”的问题：

`persistent_run.py` 与 `overleaf.py` 的 managed-block projection 使用 `rstrip()/lstrip()` 处理 marker 外内容，会改变 user-owned `AGENTS.md` 的空白字节。

这违反已批准的 C3 边界。

Bridge 对用户自有 AGENTS 内容的职责固定为：

1. 读取实际 instruction budget；
2. 计算 Bridge 自己准备写入后的 projected bytes；
3. 会超限时零写入并给出诊断；
4. 只修改 Bridge 自己拥有的 marker-delimited managed block。

Bridge 不负责：

- 自动整理用户 AGENTS；
- 自动压缩、摘要或重写用户规则；
- 删除用户规则；
- 调整用户文本格式或空白；
- 判断哪些用户内容应该被删掉。

真正的 AGENTS 内容整理属于其他专门 Skill / workflow，不属于 Bridge C3。

### Required implementation fix

在继续 C3 Gate 前：

- `persistent_run.py` 和 `overleaf.py` 改为 byte-preserving managed-block splice；
- marker 外所有原始 bytes 必须逐字节不变；
- 不对 existing user content 使用 `.strip()`、`.rstrip()`、`.lstrip()` 或换行规范化；
- 优先复用/抽取当前 Lite/core 已存在的 byte-preserving splice 语义，避免三套不同实现；
- 增加回归：包含 CRLF/LF、连续空行、尾部空白和中文内容时，更新 managed block 后 marker 外 bytes 完全一致；
- overflow 时整个项目调用继续保持 zero mutation。

这是已批准 C3 的普通实现修复，不改变产品设计，不需要新的 Planner Proposal。
