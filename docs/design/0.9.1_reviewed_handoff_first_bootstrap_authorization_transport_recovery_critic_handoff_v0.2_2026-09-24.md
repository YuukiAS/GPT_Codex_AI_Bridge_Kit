-> Bridge helper
-> repo A's own canonical sibling worktree

-> Bridge helper
-> repo B's own canonical sibling worktree

  <current-repo-parent>/<current-repo-directory-name>-<task_key>

- expected_base_commit must equal current local refs/remotes/origin/main OID;

- local branch/worktree/control-state creation only;
- no remote mutation;
- no force.

Only after these invariants hold:

task bootstrap:
prompt -> allow.

==================================================

- executable post-checkout hook, including core.hooksPath;
- configured external filter.*.smudge;
- configured external filter.*.process.

Semantics:

active checkout executable
-> BOOTSTRAP_CHECKOUT_EXECUTABLE_REQUIRES_ORDINARY_APPROVAL
-> no mutation.

Do not silently disable legitimate hooks/filters.

Review whether this is sufficient for the repo-local standing allow.
Any new blocker must identify a concrete checkout-time executable mechanism/source.

==================================================

v0.2 avoids task-specific exact-rule machinery by making every parsed accepted invocation stay inside the same safe class.
