本次公开验证只涉及 Bridge Kit 的运行通知。任务已经由真实主进程启动，状态为 RUNNING。主进程是否运行，与原始 Goal 是否完成，是两个不同的问题；RUNNING 不能改写成业务完成。

当主进程退出且 exit_code 为 0 时，系统只能报告进程以代码 0 结束。独立的项目验收尚未完成，不允许改写成 PASS。邮件传输中的 SMTP_ACCEPTED 只表示邮件服务器接受发送，不代表收件箱确认送达。
